# Clarigo image library

Review artwork is organized here without changing the live portfolio image URLs.

- `reviews/projects/<project-slug>/<phase>/`: screenshots and review artwork whose filenames identify a project.
- `reviews/by-phase/<phase>/`: shared visual reviews, contact sheets, and phase-specific comparisons.
- `../public/images/brand/`: published Clarigo and project branding.
- `../public/images/projects/`: published project screenshots and mockups, including retained source versions.
- `../public/images/thumbnails/`: published thumbnails and responsive variants.
- `../exports/`: shareable logos, thumbnails, palette guides, and delivery bundles.

Source masters and authoring inputs remain in their required source folders. The redundant nested `Clarigo-Project-Logos-1000x1000` extraction was consolidated into `exports/updated-project-logos-1000px`.

The complete image catalog, original-to-current path map, duplicate decisions, and restoration journal are in `../audit/image-library-2026-11-18/`. Every unique image content was retained. Files were moved without recompression; only unneeded byte-identical copies were removed. Different sizes, formats, and design versions remain available.

Review artwork is local archival material and is excluded from Git uploads. Production images and unpacked deliverables retain their established tracked locations.
