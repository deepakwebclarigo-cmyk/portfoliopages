# Clarigo project identity themes

18 updated-logo identities across 21 existing project pages. The remaining 27 projects retain their original colors, data, thumbnails, and artwork. The shared Clarigo navigation and footer retain the Clarigo brand palette.

Each selected page uses its own palette for navigation, buttons, section surfaces, feature icons, gallery frames, the engineering section, and the closing panel. Thumbnail templates retain the same layout and project-owned images, with a matching brand background.

The 18 enclosed transparent 1000 x 1000 PNG logos retain the subtle palette refinements already applied during the preceding color-only refresh. No logo shapes, screen geometry, text, photos, typography, or project content have been redesigned.
